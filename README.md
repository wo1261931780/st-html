# st-html

HTML5 + CSS3 系统学习代码仓库。

## 简介

本项目是 HTML5 和 CSS3 的系统学习笔记，包含从入门到进阶的完整代码示例。

## 内容概览

### HTML 基础 (aaa001-aaa006)
- **aaa001**: HTML 入门 - 初识前端、文件结构、标题、注释、换行
- **aaa002**: HTML 进阶 - 图片、超链接、锚点
- **aaa003**: 列表与表格 - 无序列表、有序列表、表格
- **aaa004**: 表单基础 - input 类型、表单属性
- **aaa005**: 语义化标签 - header、nav、article、section 等
- **aaa006**: 字符实体与表单 - 特殊字符、学生信息表

### CSS 基础 (aaa007-aaa012)
- **aaa007**: CSS 入门 - CSS 语法、引入方式
- **aaa008**: 选择器 - 标签选择器、类选择器、ID 选择器、通配符
- **aaa009**: 文本样式 - 字体、行高、文本装饰、内容居中
- **aaa010**: 盒子模型 - margin、padding、border
- **aaa011**: 背景与渐变 - 背景图片、渐变色
- **aaa012**: 浮动与定位 - float、position、z-index

### CSS 进阶 (aaa013-aaa014)
- **aaa013**: CSS 特性 - 层叠性、优先级、导航案例
- **aaa014**: 布局实战 - 常见页面布局

### 资源文件
- `img/` - 图片资源
- `audio/` - 音频资源
- `video/` - 视频资源

## 使用方法

直接在浏览器中打开 `.html` 文件即可查看效果。

```bash
# 打开某个示例
open src/aaa001/a001初认前端.html
```

## 学习路径

1. 按照 aaa001 → aaa014 的顺序学习
2. 每个文件夹内的文件按编号顺序查看
3. 结合注释理解代码含义
